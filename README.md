# VL embed-bibliotek

Felles stilark og graf-runtime for embeds laget med VL embed-bygger (Vårt Land).
Filene serveres via jsDelivr og brukes av embeds i Labrador.

| Fil | Innhold |
|---|---|
| `vl-embed-<versjon>.css` | Stilark for metric@2, timeline@2, chart@3, email@2 og sms@2 |
| `vl-embed-chart-<versjon>.js` | Graf-runtime for chart@3 |
| `chartjs-4.5.1.min.js` | Chart.js 4.5.1, uendret (MIT-lisens, © Chart.js Contributors) |

Filene genereres av byggeskriptet i VL embed-bygger og skal ikke redigeres her.
En versjon som er publisert, endres aldri. Nye versjoner får nye filnavn og en ny tag.
